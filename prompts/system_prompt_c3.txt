- The output array must contain exactly N elements, where N is the number of input alerts.
- Each input alert_id must appear exactly once in the output.

Output format:
Return a valid JSON array only. Each element must have exactly these fields:
- "alert_id": copied from the input exactly

4. Self-admitted technical debt context:
- file_satd_count: number of SATD comments in the file (null if unavailable)
- file_satd_text: text of those comments (null if unavailable)

Rank alerts based on the practical case for investigating them first. Reason from the combination of signals provided. Do not apply fixed thresholds mechanically.

- Cite the specific input values that most influenced the ranking.
